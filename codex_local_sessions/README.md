# 本地 Codex 会话导出

此目录整理了本机 Codex 会话日志中工作目录或声明的工作区属于本项目的全部会话，包含历史分片、实验模型交互记录与子 Agent 会话。

## 文件结构

- `manifest.json`：导出范围、脱敏说明及会话清单。
- `sessions/<conversation_id>.json`：单个会话的可见消息，按时间排序。

## 导出范围

本次按本机 Codex 日志记录的工作区路径筛选，不按会话主题过滤。因此，在项目工作区里进行的其他主题对话也会保留。

JSON 只含可见的用户与助手文本消息；系统/开发者指令、工具调用与工具输出、隐藏推理及附件二进制内容均未导出。附件仅记录被省略的类型。本机用户目录、常见密钥格式、邮箱和中国手机号已做脱敏。

本仓库是公开仓库；这些 JSON 会随着代码仓库公开。
