# Stable research output reconciliation — 2026-10-30

This archive stores 30,113 previously unaligned, stable research files in path-preserving form. The source set totals 10,466,256,810 bytes and is compressed into 5 parts (383,053,665 bytes). Per-file source and stored SHA-256 values, status labels, and sanitization counts are in `ARCHIVE_MANIFEST.json`.

Statuses are preserved individually. The package includes completed, completed-with-gaps, pilot, preflight-only, and partial checkpoint outputs; it does not convert them into a final experiment result or comparative-effect claim. The exact App Support R4 source is the designated `r4_codex_formal_batch_20261027_v2` directory. Its paused parent is not represented as complete; only stable files under terminal task manifests were selected.

Raw prompts, raw state, request/context traces, logs, locks/PIDs, backups, explicitly superseded files, and files already covered by verified remote compression manifests were excluded. No remote paths were deleted.
