# Data attribution and licensing notes

The archived R1 v5 simulation outputs use an OSM-derived Porto road network and background demand derived from the UCI Porto Taxi Service Trajectory dataset.

- OpenStreetMap: © OpenStreetMap contributors. Data are available under ODbL. See https://www.openstreetmap.org/copyright and the repository source note at `data/real_map_dispatch/porto_hybrid_v1/raw/osm/README.md`.
- UCI Taxi Service Trajectory: Moreira-Matias et al., “Taxi Service Trajectory - Prediction Challenge, ECML PKDD 2015,” UCI Machine Learning Repository, DOI 10.24432/C55W25. The dataset is licensed under CC BY 4.0; see https://archive.ics.uci.edu/dataset/339/taxi+service+trajectory+prediction+challenge+ecml+pkdd+2015 and the repository source note at `data/real_map_dispatch/porto_hybrid_v1/LICENSES.md`.

This file records source attribution for the derived simulation archive. Follow the source licenses when redistributing applicable data or derived database material.
