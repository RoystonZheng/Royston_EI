# R4 Codex 独立路线试跑 v7

## 本轮结果

- 地图：`grid-8x8-seed-0`，64 个节点、205 条有向边。
- 任务：`node_0_5 → node_1_2（上车）→ node_6_2（下车）`，从 v6 已校验合法的路线前缀继续。
- 零请求预检确认地图有向边语义哈希一致；从 `node_1_4` 到下车点最短还需 7 步，本轮授权上限为 8 次。
- 本轮实际使用 8/8 次 Codex CLI 请求，零重试、零工具调用、零非法动作；8 步均通过本地确定性道路及路线约束检查，模型自检与本地校验无差异。
- 模型最终到达过上车点 `node_1_2`，随后离开并停在 `node_0_1`；从最终位置到下车点仍至少需要 7 步。故结果是合法但未完成的路线前缀，不能计为完整任务成功。
- 合并初始 smoke 与 v1–v7 前缀共 22 条已执行有向边、2,200 米、263.056 秒、`energy_v1` 仿真能耗 0.4073 kWh；这些是部分路线累计值。

## Token 与费用

本轮 8 次请求共 78,904 输入 token（缓存输入 9,600，包含在输入 token 中）和 6,514 输出 token，总计 85,418 token。按 2026-10-21 核验的 GPT-5.6 Luna Codex Standard 费率复算，为 0.546740 credits 等值；按官方 API token 标价折算为 $0.02186960。Codex CLI 未报告实际订阅扣额或账户现金账单，因此这两个数均为费率等值，不是实际账单。

包含启动 smoke 及 v1–v7 父链在内，共 23 次请求、229,357 输入（缓存 9,600）和 18,767 输出 token；费率等值 1.666595 credits / $0.06666380 API 标价。来源：[Codex Standard 定价](https://developers.openai.com/codex/pricing)、[GPT-5.6 Luna API 价格](https://developers.openai.com/api/docs/models/gpt-5.6-luna)。

## 结论边界

该试跑验证了 Codex CLI 可连续返回满足结构约束且经本地门禁验证的合法动作，但模型在 8 次授权请求内未完成取送路线，并曾在抵达上车点后离开。因此它不足以准入 100×100 十种子正式路线实验，也不能与历史 DeepSeek 结果合并。正式实验仍需先冻结可比较的调用协议，并完成有明确费用上限的完整任务试跑；当前逐步模式在 100×100 图上的输入成本不具备可接受的实测预算依据。
