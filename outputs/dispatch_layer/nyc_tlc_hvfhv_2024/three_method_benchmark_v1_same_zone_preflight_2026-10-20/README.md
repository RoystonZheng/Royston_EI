# Preserved same-zone-only preflight (superseded for comparative runs)

These three offline runs were made before the shared benchmark adopted zone-centroid pickup costs. The vehicles were placed at pickup zones, same-zone pickup was zero cost, and cross-zone pickup was unavailable. D0, D1 and D2 each completed 3/4 orders with zero pickup wait and the same output totals. This is only an interface/mechanism check and is retained for audit; use `three_method_benchmark_v1` for the differentiated pickup-cost proxy.
