# C2 matching mechanism preflight

This output validates the first dispatch round for the four-order, three-vehicle C2 scenario. It is not a performance result. D0 and D1 use the same scenario fingerprint. The training-period zone OD medians represent occupied ride legs; all vehicles start in Zone 79, so pickup legs are zero by design. See `preflight_manifest.json` and the full per-method JSON files.
