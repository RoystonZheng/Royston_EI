# 调度层传统算法组运行记录

日期：2026-10-19  
状态：D0/D1 十种子离线矩阵已完成；以下为描述统计，未做显著性检验。  
结果目录：`outputs/dispatch_layer/traditional_experiment_v1/`

## 实验配置

- 方法：D0 逐订单贪心（`D0_greedy`）；D1 集中式最小费用流（`D1_optimizer`）。D2 含车辆 Agent 情境筛选，留作后续消融。
- 每种子：100×100 合成静态路网、10 辆车、1 小时、100 个随机到达订单；种子 0–9。D0/D1 在同种子下使用相同地图、订单、未按时上车标记和车辆初始位置。
- 约束：接驾等待上限 300 秒；车辆到达后等待 180 秒取消；5% 订单预先标记为乘客未按时上车；每车一对一服务。
- 上车点：每张地图固定三个不重叠区域，沿 x 轴划分为高/中/低密度带。100×100 时分别宽 16、33、51 个节点列；每笔订单等概率抽取一个区域，再在该区合法上车点中均匀抽样。面积按 100 米节点单元估算，区域边界、面积和合法点清单随结果保存。
- 路线服务：固定地图上的确定性最短时间路线查询，所有方法遵守相同路网事实和接驾硬约束。
- LLM/API：未调用，费用为 0。

## 结果

表中均值和标准差按 10 个种子计算。接驾等待及其 P95 只对完成接驾的订单统计。

| 指标 | D0 贪心 | D1 全局优化器 |
|---|---:|---:|
| 服务率 | 29.40% ± 3.53% | 29.40% ± 3.53% |
| 每种子完成订单数 | 29.40 ± 3.53 | 29.40 ± 3.53 |
| 平均接驾等待 | 193.69 ± 20.31 秒 | 193.69 ± 20.31 秒 |
| 每种子 P95 接驾等待的均值 | 290.31 ± 9.39 秒 | 290.31 ± 9.39 秒 |
| 空驶距离 | 53.14 ± 9.83 千米 | 53.14 ± 9.83 千米 |
| 模拟电耗 | 47.51 ± 5.11 千瓦时 | 47.51 ± 5.11 千瓦时 |
| 总决策耗时 | 9.26 ± 0.71 秒 | 9.43 ± 0.66 秒 |
| 优化/分配阶段耗时 | 2.31 ± 0.09 毫秒 | 1.37 ± 0.11 毫秒 |

D0 和 D1 在每一个种子的每一轮都选出相同的候选，最终指标完全相同。每种方法共记录 2,311 个调度轮次；没有一轮同时出现多辆候选车和多个可行候选订单的二分冲突。该矩阵没有展示全局优化器相对贪心的服务结果优势，结论仅限本模拟器和本批场景。

10 个种子的上车区域订单数合计为高密度 334、中密度 328、低密度 338。合并订单后的服务率分别为 19.16%、28.35%、40.53%；这些是当前合成地图上的描述结果，不单独解释为热点面积的因果效应。12 个五分钟时间窗口和三个热点的逐方法统计见随附 CSV。

## 完整性核对

- 20 个方法—种子结果全部存在；每个种子 D0/D1 的场景 SHA-256 相同，且地图、订单输入和车辆初始位置逐项一致。
- 每个种子恰有 100 个订单和 5 个 no-show 标记；最终订单状态之和为 100。
- 所有调度轮次的统一校验状态均为 `valid`；未发现未来订单可见、承诺违约或超过 300 秒的接驾等待。
- 已发生的乘客未按时上车取消均在车辆到达后 180 秒发生；未服务订单记为 `timeout`。
- 结果清单含 20 份完整 JSON、矩阵 manifest、五分钟窗口汇总和热点汇总。没有运行测试套件，也没有调用外部模型/API。
