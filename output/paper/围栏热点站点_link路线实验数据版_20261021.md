## 3. 研究问题与结论边界

**研究问题：** 在完全相同的有向路网、站点绑定和 OD 任务下，把原始 Link 记录改成显式类型化的 Link—后继关系，能否提高 LLM 生成有效路线的比例，并降低搜索成本？

本包最适合检验有向拓扑表达的可读性。它没有道路名称、语义类别字典或路侧设施关系，因而不能用它单独声称语义地图特征带来了收益。后续如取得有字典的道路语义/设施数据，可另加一组因素，不回填或推断本包没有的属性。

## 4. 固定任务和地图口径

1. **冻结输入。** 使用完整的 12,868 条候选 Link，不按 192 个站点的外包框二次裁图。固定地图版本、文件哈希、站点名单和任务名单；所有方法读取同一快照。
2. **站点与端点。** 当前正式路线任务直接使用站点已提供的 esw_link_id 作为起终点 Link，把“点到 Link 匹配”排除在主实验之外，避免把已有标签误当成模型能力。若以后单独测匹配，必须隐藏绑定列，并把 point_id 改成随机别名，因为当前 point_id 后缀可反推出绑定 Link；同时先确认坐标系。
3. **OD 集合。** 传统算法可穷举 126 个绑定 Link 之间的 15,750 个有序异 Link OD。LLM 初步试验建议从中分层抽取 30 对，按最短路径 Link 数和长度分层；正式样本规模在上下文/调用预算预检后冻结。热度用于站点或任务分层，不作为道路拥堵权重，也不假定 pickup_heat 与 dropoff_heat 构成真实 OD 联合分布。
4. **围栏范围。** 当前先把 fence10089 作为场景标识和站点来源范围，路由使用原矩形候选路网。对原始经纬度与 gcj_fence 做的数值包含检查显示 192 个点均落在该坐标多边形内，但数据包将坐标系标为未确认；因此该检查不作为权威地理包含证明。确认坐标系和边界解释后，才能另设“严格围栏内路由”实验。
5. **成本和路径。** 主目标使用 Link.length（包内单位说明为米）之和，搜索只沿当前 Link 的 out_links。站点到 Link 的精确沿线偏移尚未验证，故起终 Link 暂按全长计入，并明确这是 Link 级距离代理。没有依据时不把 speed_class 转成 ETA，也不从 direction 数字代码推断道路含义。
6. **外部邻接。** 道路输入保留所有原始邻接引用；路径校验只接受同时存在于冻结候选集中的 Link。需要跨越候选矩形边界的路线应另做补图版本，不得静默把未知 Link 接成边。

## 5. 方法对照

- **T0：Link-Dijkstra。** 在全量候选有向图上用 Link.length 求最短距离，作为确定性参考；所有路径由独立校验器复核。
- **T1：LLM-flat。** LLM 通过固定地图查询接口看到原始/平铺 Link 记录及邻接，直接输出有序 Link 序列。
- **T2：LLM-typed。** 使用同一模型、任务、地图事实、查询端点和最大查询预算；查询响应只改成有字段定义的 DirectedLink、Successor 和 StationBinding 结构，LLM 直接输出路径。T1 与 T2 的差异用于评估拓扑表达格式，不增加额外道路事实。
- **T3：Agent-readable + 传统路由器。** Agent 查询同一类型化地图协议，确定端点和候选范围，再调用固定 Dijkstra；该组评估完整工作流，与 T1/T2 的 LLM 直接路线生成结果分开报告。

T1/T2 是“LLM 借助同一只读地图查询接口生成路线”的配对条件，不应称为把整份地图直接塞进提示词的纯 LLM。若另做无工具纯 LLM 组，必须先证明任务所需的完整公共子图能放入上下文；否则不把上下文截断造成的缺边当成模型能力差异。

12,868 条 Link 不应未经上下文预检就整包塞进模型提示。若完整图超过目标模型上下文或预算，T1/T2 都通过相同查询接口按需取得同一候选图事实；记录每题可见 Link 集合、查询次数和 token。不得只给某个方法裁剪更小的地图，也不得用 Dijkstra 最终路线生成模型可见的候选集合。

## 6. 公平性与验证

所有方法共享冻结的地图哈希、map_version、起终 Link、OD 任务、Link.length、路由边界和验证器。模型输出仅允许 Link ID 序列；评估器检查：ID 是否存在、首尾是否匹配、每个相邻 Link 是否满足当前 Link 的 out_links、路径是否只经过输入候选图。以上只能称为“输入拓扑一致”，不能替代真实行车规则检查。

主要指标：拓扑有效率、可达任务完成率、相对 Dijkstra 的长度差与最优差距、Link 序列错误类型、查询/展开 Link 数、输入输出 token、响应和求解时延。把“无法解析地图”“超出候选范围”“模型未构造路径”“路径合法但非最短”分开统计。
