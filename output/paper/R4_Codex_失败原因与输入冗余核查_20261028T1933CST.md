## 当前冻结方案核查

- 路线输入为 `r4-step-v3`：地图使用语义等价审计通过的紧凑方向成本编码；输入剔除了冗余地图元信息。动态输出 schema 限制当前允许的方向；程序在模型外重新核验有向边、边界、回访与接送顺序。模型给出的 `self_check` 只留作诊断记录，合法性以确定性校验器为准。
- 单步决策与可见自检字段属于逐步路线生成；不能据此声称观察到了模型私有 CoT。
- 当前 formal batch 使用 isolated/ephemeral CLI 请求，每一步会重发完整紧凑地图和当前状态（worker manifest 的 `per_step_map_payload` 明确记录）。这属于可确认的 token 冗余/吞吐瓶颈，但不是上述 35 个 CLI error 的直接原因。
