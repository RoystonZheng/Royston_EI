# R4 当前卡点诊断与修复路径

**核对日期：2026-10-26**  
**范围：** 只审计已有 R4 请求、冻结预检与离线产物；本次新增模型请求为 0。

## 结论

R4 当前的主要问题不是地图非法、validator 失效或 API 普遍不返回，而是模型能持续选择“局部合法、全局绕行”的方向；单方向一次请求的协议又把这种绕行放大成大量请求和输入 token。实验尚无完整 R4 路线，不能作为完成结果。

## 对用户两项建议的判断

两项建议方向正确，而且已经落实：地图压缩降低了序列化负担；程序 validator 确保非法边不进入已接受路线。它们解决的是输入冗余和约束安全，不会自动让模型朝终点推进，所以重复加强“请逐步自检”的提示本身不足以修复当前主故障。合法性结论必须来自程序。补充复查还发现，旧运行曾把模型自检与本地事实不一致也当成硬失败：8×8 v3 的第7次提议方向被确定性检查判为合法，但模型把 `target_node_is_new` 报为 false，路线因此提前停止。v6 候选已修正为记录自检差异、由本地 validator 单独决定是否合法。
