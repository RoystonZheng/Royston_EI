# 引言

本文研究一对一无人网约车平台中的动态派单与接驾路线评估。订单持续到达、车辆状态不断变化时，平台需要在线匹配车辆与订单，并规划车辆驶向乘客指定上车点的路线；每辆车同一时刻服务一名乘客，完成当前订单后再接受下一单。本文将乘客等待时间定义为派单计算时间与车辆接驾运行时间之和，并将最大等待时间设为硬约束，优先降低平均等待时间[1]。

已有研究分别涉及在线匹配与车辆调位、多目标无人车派单、多智能体学习、地图表示与导航，以及 LLM 和数学优化器的分层协同[2–8]。这些工作覆盖了动态运营中的多类方法，但研究对象和决策环节并不相同。本文聚焦于固定上车点的一对一服务：如何把车辆侧的路线可达性与代价评估，转化为车队级优化器可用于全局派单的信息。相关工作的具体脉络与任务差异见相关工作部分。

本文拟采用车辆 Agent 与全局数学优化器协同的工作流。每辆无人车对应一个 Agent，Agent 工作流包含模型调用环节，读取本车状态、订单信息和可查询地图，形成或筛选接驾路线候选；路线检查模块核验可达性并估算接驾时间和资源消耗；全局优化器汇总结构化候选，在硬约束下作出最终车辆—订单分配。由于 LLM 与优化器的组合已有先行研究[8]，本文不以二者的简单结合为创新主张，而关注单车评估结果如何通过明确接口支持全局派单。

本文拟在模拟环境中开展以下研究：

1. **Agent—优化器协同：** 明确车辆 Agent、路线检查模块与全局派单优化器之间的输入、输出和决策边界。
2. **面向 Agent 的地图表示：** 组织可查询的路网连接、道路属性和场景约束，为指定上车点的路线评估提供一致信息。
3. **时间优先的派单评估：** 在最大等待时间约束下优先优化平均等待时间，再比较计算与行驶资源消耗；通过分层模拟对照检验各模块的作用，如实报告超时、未服务和积压情况，不预设性能优势。
