# 一对一无人网约车 Agent 协同研究

本仓库保存课程研究的文稿、Agent 工作流和两层模拟实验设计。研究对象是一对一动态无人网约车：每辆车同一时刻服务一名乘客，当前订单完成后再接受后续订单。

## 入口文件

- [AGENTS.md](AGENTS.md)：项目协作规则和研究边界。
- [研究记忆库.md](研究记忆库.md)：当前确认结论、方案假设、证据边界和未决事项。
- [第三次课_Agent工作流完善稿.md](第三次课_Agent工作流完善稿.md)：Agent—LLM—优化器的工作流草案。
- [EXPERIMENT_DESIGN.md](EXPERIMENT_DESIGN.md)：路线层和调度层实验总览。

## 当前进度（2026-10-10）

- 已完成路线层和调度层的首版实验设计、统一输入输出字段以及主要消融关系。
- 方案采用可复现的离散路网和动态订单模拟；当前文件属于设计稿，尚未代表已经完成的实验或真实道路验证。
- 首轮路线和调度实验固定使用 DeepSeek V4 Flash API；Hugging Face 预训练模型作为后续模型比较，不改变首轮控制变量。

### 路线层

- [路线层实验方案_20261009.md](路线层实验方案_20261009.md)

### 调度层

- [调度层实验方案_20261009.md](调度层实验方案_20261009.md)

## 证据边界

文稿和字段是研究设计证据；模拟运行、重复实验结果和真实部署验证分别记录。没有运行记录时，不把预期优势写成实验结论，也不把模拟结果写成真实道路效果。
