# 一对一无人网约车 Agent 协同研究

本仓库保存课程研究的文稿、Agent 工作流和两层模拟实验设计。研究对象是一对一动态无人网约车：每辆车同一时刻服务一名乘客，当前订单完成后再接受后续订单。

## 入口文件

- [AGENTS.md](AGENTS.md)：项目协作规则和研究边界。
- [研究记忆库.md](研究记忆库.md)：当前确认结论、方案假设、证据边界和未决事项。
- [第三次课_Agent工作流完善稿.md](第三次课_Agent工作流完善稿.md)：Agent—LLM—优化器的工作流草案。
- [EXPERIMENT_DESIGN.md](EXPERIMENT_DESIGN.md)：路线层和调度层实验总览。

## 当前进度（2026-10-14）

- 已完成路线层和调度层的首版实验设计、统一输入输出字段以及主要消融关系。
- 路线层已跑通种子 0 的 100×100 地图、独立订单、正式场景、R0/R1/R2 传统路线和统一费用评估。70% 精确节点与 30% 语义地点混合任务均可完成；传统基线的语义任务使用固定 `graph_only` 解析器，不读取路牌/电线杆语义，也不读取评估器真值，因此不会因道路特征不可见而被直接判为失败。
- 已增加种子 0–1 的 100×100 离线烟雾测试：检查地图/订单确定性、70/30 比例、五类正式场景、R0/R1/R2 和非零参考价格换算。当前价格配置引用 [Tesla 中国官方深圳站点页面](https://www.tesla.cn/findus/location/supercharger/cnsc9691?region=CN) 的峰时综合充电服务价 2.29 CNY/kWh，并记录站点、时段、日期、来源和价格口径。
- 已完成第一轮传统算法正式实验：10 个 100×100 地图种子、每个种子 10 条 70/30 混合订单和 5 类正式场景，运行全图 Dijkstra、局部 Dijkstra、局部 A*；订单任务三种方法均为 10/10 完成，正式场景按可行/边界/绕行成功、非法端点/不可达失败记录。每个任务—方法组合均保留搜索扩展事件、最终路线、成本结果和独立 HTML 回放，共 450 条轨迹记录。
- 第一轮传统实验入口为 `scripts/run_traditional_experiment.py`，总索引为 `outputs/route_layer/traditional_experiment_v1/index.html`，清单为 `outputs/route_layer/traditional_experiment_v1/manifest.json`。该结果仍是离线仿真基线，不代表 Agent 优势、LLM 效果或真实道路效果。
- `RoadFeatureInputProtocol v1`、纯 LLM/Agent 工作流和 Agent-readable 对照仍属于后续实验；它们应复用本轮相同的地图、订单和验证/成本口径。
- 首轮路线和调度实验固定使用 DeepSeek V4 Flash API；Hugging Face 预训练模型作为后续模型比较，不改变首轮控制变量。

## 两层实验文件

### 路线层

- [路线层实验方案_20261009.md](路线层实验方案_20261009.md)
- [路线层实验字段_20261008.md](路线层实验字段_20261008.md)

路线层在同一张离散道路图和同一输入包上比较全图/局部 Dijkstra、A*、纯 LLM 和车辆 Agent 工作流，并检查 Agent 友好地图输入以及 Agent 搭配传统路线算法或 LLM 路线模块的消融。精确任务共享同一解析后输入包；语义任务共享原始文本和道路图，由各方法解析候选后使用同一验证与评估链路。

### 调度层

- [调度层实验方案_20261009.md](调度层实验方案_20261009.md)
- [调度层实验字段_20261009.md](调度层实验字段_20261009.md)
- [实验方案_Agent候选与调度字段草案_20261008.md](实验方案_Agent候选与调度字段草案_20261008.md)

调度层使用 10 辆车、1 小时和动态订单，所有方法共享完整候选表、硬最大接驾等待约束和统一校验器；最终派单由数学优化器决定，纯 LLM 仅作为直接派单对照。

## 证据边界

文稿和字段是研究设计证据；模拟运行、重复实验结果和真实部署验证分别记录。没有运行记录时，不把预期优势写成实验结论，也不把模拟结果写成真实道路效果。
