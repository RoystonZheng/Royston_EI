# Dataset licenses and attribution

The bundle contains inputs with different licenses. Keep them identifiable and do not apply one blanket license to every source file.

## UCI Porto Taxi trajectories

- Source: UCI Machine Learning Repository, *Taxi Service Trajectory—Prediction Challenge, ECML PKDD 2015*.
- DOI: <https://doi.org/10.24432/C55W25>
- Dataset page: <https://archive.ics.uci.edu/dataset/339/taxi%2Bservice%2Btrajectory%2B%20prediction%2Bchallenge%2Becml%2Bpkdd%2B2015>
- License indicated by UCI: Creative Commons Attribution 4.0 International (CC BY 4.0).
- Attribution: cite the dataset title, creators as listed by UCI, DOI, and CC BY 4.0. Preserve the UCI source page and license URL alongside any redistributed copy.
- Retrieval copy: Ali Dorosti (2023), [figshare record](https://doi.org/10.6084/m9.figshare.24796053.v1), CC BY 4.0. This is recorded as a download mirror; cite UCI DOI `10.24432/C55W25` as the dataset source and retain the mirror attribution where the copied file is redistributed.

## OpenStreetMap

- Source: OpenStreetMap contributors.
- License: Open Database License (ODbL).
- Attribution: “© OpenStreetMap contributors” with a link to <https://www.openstreetmap.org/copyright>.
- Keep OSM-derived database files and notices separate from non-OSM inputs. Review ODbL obligations for any combined or materially derived database before public redistribution.

## SUMO-generated scenario files

SUMO-generated traffic states are experiment outputs, not observed city measurements. Record the SUMO version, configuration, traffic seed, network source, and demand-generation script. The SUMO software itself is distributed under EPL-2.0; this does not by itself assign a license to the experiment data.

## Project code and documentation

The repository owner should select a license for original scripts and experiment documentation separately. This notice does not relicense UCI or OSM data.
